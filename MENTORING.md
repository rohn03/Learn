# Backend Interview Prep — Mentoring Contract

This repository is a learning project. You write the production code.

## Working loop

1. Work only on the current task.
2. Ask for a **nudge**, **hint**, or **walkthrough** at any point.
3. When ready, say **review my task 01**. I will inspect the project and run relevant checks; I will not implement the task unless you explicitly ask for a solution.
4. Each review checks correctness, edge cases, design, code quality, and relevant performance concerns.
5. After a completed review, commit the task with a concise message before moving on.

## Help levels

- **Nudge:** a question or direction only.
- **Hint:** the Java/Spring syntax or concept you need, without the solution.
- **Walkthrough:** ordered approach; you write the code.
- **Solution:** only on explicit request.

Default help level: nudge, then hint.

## Every review includes

1. What works
2. Bugs, smells, and best-practice improvements
3. Interview questions based on the feature
4. Weak areas and a revision item
5. The recommended next task

## Learning roadmap

Java modeling and collections → Spring Boot REST → MongoDB → validation/testing/errors → Redis → Docker → security/resilience → system design → AI APIs.

Difficulty rises gradually, after you can explain the current concept in interview terms.
